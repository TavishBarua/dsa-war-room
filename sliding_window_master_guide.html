📚 The Two Types of Sliding Window

🎯 GOLDEN RULE: Ask yourself - "Is the window size FIXED or FLEXIBLE?"

Type 1: STATIC (Fixed) Window 📏

Window size = CONSTANT

  • ✅ "Maximum sum of K elements"
  • ✅ "Average of subarrays size K"
  • ✅ K is given in the problem

Think: Sliding a ruler of FIXED LENGTH

Type 2: DYNAMIC (Flexible) Window 🎢

Window size = CHANGES

  • ✅ "Longest substring with..."
  • ✅ "Smallest substring with..."
  • ✅ "Find window that satisfies condition"

Think: Window GROWS and SHRINKS like an accordion

Type 1: STATIC Window - The Fixed Ruler 📏

🔑 TRICK: Move 1 step → Remove LEFT, Add RIGHT
// ✨ STATIC WINDOW TEMPLATE ✨ for (int right = 0; right < arr.length; right++) { // 1. ADD the new element on RIGHT windowSum += arr[right]; // 2. Check if window is complete (size = K) if (right >= K - 1) { // 3. Process current window (calculate answer) maxSum = Math.max(maxSum, windowSum); // 4. REMOVE the LEFT element before sliding windowSum -= arr[right - K + 1]; } }
📐 LEFT pointer = right - K + 1

Type 2: DYNAMIC Window - The Accordion 🎢

🔑 TRICK: EXPAND (right++) until BAD → SHRINK (left++) until GOOD

Two Sub-patterns:

  • Pattern A: LONGEST/MAXIMUM - Find biggest valid window
  • Pattern B: SHORTEST/MINIMUM - Find smallest valid window (like your code!)

Pattern A: LONGEST Window Template

// ✨ DYNAMIC WINDOW - LONGEST PATTERN ✨ int left = 0, maxLength = 0; for (int right = 0; right < arr.length; right++) { // 1. EXPAND: Add right element to window addToWindow(arr[right]); // 2. SHRINK: While window is INVALID, remove from left while (windowIsInvalid()) { removeFromWindow(arr[left]); left++; } // 3. UPDATE answer (window is valid now) maxLength = Math.max(maxLength, right - left + 1); }

Your Code: SHORTEST/MINIMUM Window Pattern 🎯

🧠 MINIMUM TRICK: EXPAND until VALID → SHRINK to find SMALLEST

Problem: Find SMALLEST substring of s that contains ALL characters of t

Example: s = "ADOBECODEBANC", t = "ABC"

Pattern B: SHORTEST/MINIMUM Window Template

// ✨ DYNAMIC WINDOW - SHORTEST/MINIMUM PATTERN ✨ int left = 0, minLength = Integer.MAX_VALUE; for (int right = 0; right < arr.length; right++) { // 1. EXPAND: Add right element addToWindow(arr[right]); // 2. SHRINK: While window is VALID, try to minimize while (windowIsValid()) { // Update answer before shrinking minLength = Math.min(minLength, right - left + 1); removeFromWindow(arr[left]); left++; } }
Key Difference:
  • LONGEST: while INVALID → shrink until valid
  • SHORTEST: while VALID → shrink to minimize

🔍 Your Code - Line by Line Breakdown

1️⃣ Setup - Count what we need
Map<Character, Integer> tCount = new HashMap<>(); // Count each char in target string t // Example: t="ABC" → {A:1, B:1, C:1}

💡 This tells us: "I need 1 A, 1 B, 1 C"

2️⃣ Variables
int required = tCount.size(); // How many UNIQUE chars (3 for "ABC") int formed = 0; // How many we've satisfied (0 → 1 → 2 → 3)

💡 formed == required means "I have ALL the chars I need!"

3️⃣ EXPAND Phase - Add right character
char c = s.charAt(right); windowCount.put(c, windowCount.getOrDefault(c, 0) + 1); // If this char is now satisfied (count matches target) if (tCount.containsKey(c) && windowCount.get(c).intValue() == tCount.get(c).intValue()) { formed++; // One more char type satisfied! }

💡 We're building up the window, counting characters

4️⃣ SHRINK Phase - When window is VALID
while (left <= right && formed == required) { // Window is VALID! Try to make it SMALLER // Save this as potential answer if (right - left + 1 < minLen) { minLen = right - left + 1; resultLeft = left; resultRight = right; } // Remove left char and move left pointer char leftChar = s.charAt(left); windowCount.put(leftChar, windowCount.get(leftChar) - 1); // If removing this char breaks the condition if (tCount.containsKey(leftChar) && windowCount.get(leftChar) < tCount.get(leftChar)) { formed--; // No longer satisfied } left++; }

💡 Keep removing from left while we still have all chars we need

📋 Ultimate Cheat Sheet

Pattern Type When to Use Key Trick While Loop
STATIC Size K is given Remove left, Add right if (right >= K-1)
LONGEST Find max/longest valid Expand → Shrink INVALID while (INVALID)
SHORTEST Find min/smallest valid Expand → Shrink while VALID while (VALID)
🎓 MASTER TRICK: LONGEST shrinks when BAD, SHORTEST shrinks when GOOD!

🎯 How to Identify Pattern in 3 Seconds

Ask these questions:
  1. Is size K given? → STATIC window
  2. Says "longest/maximum"? → LONGEST pattern (shrink when invalid)
  3. Says "shortest/minimum"? → SHORTEST pattern (shrink when valid)
